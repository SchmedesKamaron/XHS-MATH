## 📩 投稿 & 勘误流程
如果你有想要求解的数学题目，或者发现已有解答存在错误，可以通过邮件联系我：

- ✉️ **投稿新题目**：发送题目到 `zoexiong@fantastic-studio.top`
  - 邮件建议附带：题目原文、你的想法（可选）；
  - 收到后，我会整理完整解题步骤，上传到本仓库。

- ✉️ **勘误（解答有误）**：发送勘误信息到 `ceo@fantastic-studio.top`
  - 邮件建议附带：题目链接 / 文件名称、错误位置、正确推导；
  - 核实之后会及时提交修正。

> 提示：我会按收到顺序处理，无法保证即时回复。
